# vepr-contracts — AGENTS.md

## What this repo is
The single source of truth for every message that crosses a repo boundary in Vepr:
- openapi/partner.yaml — bank-facing REST API (/v1/...)
- openapi/device.yaml — phone-facing REST API (/v1/device/...)
- proto/vepr/credentials/v1 — internal gRPC (CredentialService)
- proto/vepr/events/v1 — events published through NATS JetStream
- signing/ — canonical signed payload: SPEC.md, test vectors, reference encoders (Java + Swift)
- docs/ — ARCHITECTURE.md, CONVENTIONS.md, ERRORS.md (read these first, always)

## Hard rules
- No business logic. Encoders/verifiers for the signing format are allowed (they are the contract).
- Never change signing v1 bytes. New format = new version byte + new vectors + SPEC section.
- Never make a breaking change to a published contract without: a major version bump, an entry in CHANGELOG.md, and my explicit approval. `buf breaking` and the OpenAPI diff must pass otherwise.
- Every schema field has a description, type, format, and bounds (minLength/maxLength/minimum/maximum/pattern). No free-form objects. additionalProperties: false everywhere.
- JSON is snake_case. IDs are UUIDv7 strings. Times are RFC 3339 UTC with ms. Money is amount_minor (int64) + currency. Binary is base64url without padding.
- Keep openapi/device.yaml and Sources/VeprDeviceAPI/openapi.yaml identical (scripts/sync-swift.sh); the same for signing vectors copied into Swift test resources. CI checks both.
- Test vectors are generated by code in this repo, committed, and verified by every implementation.

## Layout
openapi/  proto/  signing/{SPEC.md,vectors/}  docs/  java/ (Gradle: contracts-openapi, contracts-proto, contracts-signing)
Package.swift + Sources/{VeprSigning,VeprDeviceAPI} + Tests/  (Swift package consumed by vepr-ios-sdk)

## Commands
- Spec lint: `npx @redocly/cli lint openapi/*.yaml`
- Breaking check: `oasdiff breaking <last-tag-spec> openapi/<file>.yaml`, `buf breaking --against '.git#tag=<last-tag>'`
- Proto lint: `buf lint`
- Java: `cd java && ./gradlew check`
- Swift: `swift test`
- Sync Swift copies: `scripts/sync-swift.sh` (CI runs it with --check)

## Definition of done
All of the above pass, CHANGELOG.md updated, version bumped per SemVer (additive = minor).
